# FDI Prototype Brand Guidelines

## Quick Reference

| Token | Value | Use |
|---|---|---|
| Primary Color | #0B5CAD | Primary actions, links, selected states, map markers |
| Secondary Color | #09090A | Navigation, headers, high-emphasis controls |
| Accent Color | #FFFFFF | Surfaces, reversed text, breathing room |

## Brand Concept

FDI uses a direct, professional blue-white-black identity. Blue communicates action and trust, black provides operational authority, and white keeps dense facilities information clear. Amber and red are reserved for warnings, urgent conditions, and compliance blocks; they are semantic signals rather than brand colors.

## Usage

- Use FDI Blue for primary buttons, active tabs, links, and map markers.
- Use FDI Black for navigation and external-portal headers.
- Use white and cool gray surfaces for content and tables.
- Do not use green as a general success or brand color in this prototype.
- Continue pairing status colors with text or icons so meaning never depends on color alone.
